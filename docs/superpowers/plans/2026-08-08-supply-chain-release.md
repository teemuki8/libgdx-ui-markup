# Supply Chain and 0.3.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development for issue #26 and superpowers:finishing-a-development-branch for final integration. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix issue #26, merge every reviewed domain PR, and publish/verify release 0.3.0.

**Architecture:** Lock every resolvable dependency graph after feature PRs stabilize it; enforce strict Gradle verification in CI and release. Release from one reviewed main commit through the existing signed-tag Maven Central workflow.

**Tech Stack:** Gradle 9.6.1 Wrapper, GitHub Actions, GPG, Maven Central Portal, GitHub CLI.

## Global Constraints

- Generate lock/verification state only after all code PR dependency changes are known.
- Review every new coordinate/repository before trusting generated checksums.
- Never expose signing or Central secrets.
- Merge only reviewed exact heads with successful required checks.
- Release completes only after Central `PUBLISHED`, public coordinate resolution, and GitHub release creation.

### Task 1: Enable Dependency Locking (#26)

**Files:**
- Modify: `build.gradle.kts`
- Modify module build files only where a resolvable configuration needs explicit handling.
- Create: root/module `gradle.lockfile` files generated by Gradle.
- Test: build configuration through Gradle commands.

**Interfaces:**
- `dependencyLocking { lockAllConfigurations() }` applies consistently to all projects, including IDEA and qualification configurations used by CI/release.

- [ ] Run `./gradlew dependencies --write-locks` on a temporary branch state to expose currently unlocked configurations; do not commit until configuration is explicit.
- [ ] Configure all projects to lock resolvable configurations and regenerate locks with the wrapper.
- [ ] Run normal `./gradlew help`/`check` without `--write-locks`; mutate one lock in a disposable copy and prove resolution fails on drift.
- [ ] Review lock files for dynamic/changing versions and unexpected repositories; remove the cause rather than pinning an unexplained artifact.
- [ ] Commit `build: lock resolved dependencies`.

**Interfaces:**
