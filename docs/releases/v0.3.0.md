# libgdx-ui-markup 0.3.0

## Highlights

- semantic model and parser correctness: parent-scoped element paths, located range diagnostics,
  one-based CSS source coordinates, bounded grouped selectors and cascade work, tagless
  pseudo-state selectors, pseudo-state font colors, explicit `false` layout handling, and
  failure-safe `DefaultSkin` Pixmap ownership;
- runtime contracts: transactional registration and rollback, explicit authoritative runtime
  values, typed correlation status/reasons, and adapter behavior that preserves genuine
  `UNAVAILABLE` results instead of collapsing them into stale state;
- deterministic preview and IDEA lifecycle: bounded pre-read input, transactional rebuild and
  runtime attachment, upright deterministic screenshots, typed preview status, in-memory
  bounded artifacts, render-thread waits, and owned child-process/drain cleanup on every
  supported host;
- qualification trust boundaries: contained corpus paths, authenticated HTTPS references with
  mandatory byte identity, bounded in-memory transfer/decode/cache behavior, bounded manifest
  and total work, one monotonic deadline, and retryable close ownership until all work drains;
- visual qualification now gates geometry, spatial color, and detail independently at a fixed
  analysis resolution, with immutable absolute floors, deliberate negative transformations,
  floor-aware calibration/staleness, and actionable schema-v2 reports;
- strict dependency locking and dependency verification cover every CI/release resolution
  graph, with committed lockfiles, checksums, and artifact-scoped signing trust.

All GitHub issues open at the start of this release cycle (#5 through #28) are closed by the
reviewed domain pull requests.

## Compatibility

The 0.3.0 public Java API is additive relative to 0.2.1. Existing entry points remain, while
runtime and preview state gain explicit typed contracts. Parsing, CSS, lifecycle, and trust
boundaries are intentionally stricter: inputs that were ambiguous, unbounded, or silently
misclassified now fail with typed diagnostics.

Published modules require Java 25 and libGDX 1.14.2; the harness adapter requires harness
1.1.0.
