# libgdx-ui-markup 0.6.0

## Highlights

- Adds document-local reusable markup components with bounded `<components>`, `<component>`,
  `<param>`, `<use>`, `<slot>`, and `<fill>` syntax.
- Supports required and defaulted parameters, required and fallback slots, nested composition,
  root attribute overrides, and deterministic class merging.
- Expands components in the GL-free parse layer into ordinary immutable elements before
  `MarkupBuilder`; Scene2D actors and the harness never observe component-only nodes.
- Adds immutable source and invocation provenance through `MarkupSourceLocation`,
  `ElementProvenance`, `ComponentTraceFrame`, and `MarkupDiagnosticContext`.
- Adds typed component diagnostics, bounded deterministic nearest-name suggestions, and component
  trace presentation in the preview and IntelliJ plugin.
- Upgrades preview `markup-status` to schema 3 with bounded structured fields while retaining
  transactional last-good hot reload behavior.
- Updates the sign-in fixture, README, ADR, and executable agentic cookbook recipes to exercise
  components through parse, build, preview, harness, and IDEA integration paths.
- Hardens the parser trust boundary with 256-character XML/custom-tag names, at most 256 custom
  tags per parser, and explicitly bounded suggestion candidate work.

## Compatibility and scope

Component-free markup retains its existing concrete element and actor behavior. The existing
two-argument `MarkupDocument(Element, int)` constructor and its `root()` / `byteLength()` accessors
remain available; new source/provenance accessors are additive. Existing `MarkupException`
construction and location accessors remain available, with additive structured context and
component-specific kinds.

Consumers that parse the preview's `markup-status` line must accept schema version 3 and its new
structured diagnostic fields. The preview and IDEA plugin remain unpublished application/tooling
artifacts.

Component syntax is deliberately document-local and bounded. There is no component discovery,
file or URL import, dynamic tag construction, loop, conditional, arithmetic, script, reflection,
implicit ID namespace, runtime-state ownership, or arbitrary Java invocation.

Published modules require Java 25 and libGDX 1.14.2. The release gate qualifies harness 1.2.0 /
agent-runtime 2.0.0 and the minimum harness 1.1.0 / agent-runtime 1.0.0 profile. V1 remains scoped
to LWJGL3 desktop and Scene2D/Scene2D.UI.
