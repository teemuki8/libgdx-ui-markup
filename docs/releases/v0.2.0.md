# libgdx-ui-markup 0.2.0

## Highlights

- the three-library story is complete: markup-declared `data-runtime-entity` widgets compare
  `EQUAL` through the harness `ui_runtime_compare` MCP tool with typed frame correlation
  (ADR 0002), against the published harness 1.1.0;
- `HarnessSemanticSink` binds runtime entities into the harness `Semantics` facade during the
  build pass, carrying the `markup-preview-frame` correlation token;
- the preview serves the runtime-compare capability and coordinator, mirroring the harness
  reference fixture wiring;
- a Maven Central publishing pipeline: deterministic signed bundles, fail-closed release
  configuration, staged-artifact and unpublished-module verification, and a signed-tag release
  workflow that uploads, validates, and publishes user-managed deployments;
- Apache 2.0 license text embedded in every published main, source, and Javadoc JAR;
- strict Javadoc linting (doclint + `-Werror`) on all published modules.

## Compatibility

The 0.2.0 API is source- and binary-compatible with 0.1.0. Published modules require Java 25
and libGDX 1.14.2; the harness adapter requires harness 1.1.0.

## Maven coordinates

The release contains:

- `io.github.teemuki8:libgdx-ui-markup:0.2.0`
- `io.github.teemuki8:libgdx-ui-markup-runtime:0.2.0`
- `io.github.teemuki8:libgdx-ui-markup-harness:0.2.0`

The preview (runnable app distribution) and the IDEA plugin (marketplace channel) remain
repository-only.
