# libgdx-ui-markup 0.5.0

## Highlights

- Establishes `.gdxcss` as the canonical stylesheet extension so tools and AI agents do not
  mistake the bounded Scene2D dialect for browser CSS. Existing `.css` paths remain accepted.
- Adds live relative Scene2D layout: `width`, `height`, `min-*`, and `max-*` accept bounded
  pixels, percentages, and `auto`. In a Table Cell, `width: 100%` and other percentages remain
  live through later container and viewport resizes without rebuilding the actor tree.
- Adds CSS-shaped spacing and layout conversions for padding, margin, gaps, display, visibility,
  Table clipping, and vertical alignment while continuing to use Scene2D's Table/Cell engine.
- Adds practical bounded styling for colors, background tint, font aliases, wrapping and
  ellipsis, image fit/position, opacity, pointer behavior, scale, rotation, and transform origin.
- Expands selectors to bounded compounds, multiple classes, IDs, descendant and child
  combinators, comma groups, and supported widget pseudo-states. Matching retains explicit
  specificity and per-resolution/per-build work limits.
- Adds bounded `:root` design tokens with forward references, cycle detection, a 256-variable
  cap, and a 16-reference depth cap. Unknown properties, incompatible actor targets, malformed
  selectors, and unsupported values remain located typed errors.
- Adds an AI-first agentic cookbook with executable recipes for parsing, building, responsive
  layout, selectors/tokens, semantic locators, preview/MCP workflows, custom tags, and typed
  failure diagnosis.
- Adds dedicated IntelliJ `.gdxcss` file recognition and bounded syntax highlighting; preview,
  qualification, harness, samples, and documentation use the canonical extension.
- Fixes installed IntelliJ plugin preview launches by resolving the bundled preview distribution
  from the plugin descriptor's installation path.

## Compatibility and scope

The public Java conveniences changed by this release retain source-compatible constructors and
accessors. Existing `.css` files and legacy comma-form spacing remain accepted. New stylesheets
should use `.gdxcss` and CSS-order whitespace spacing values.

This is deliberately not a browser engine. Flexbox, grid, floats, positioning, media queries,
inheritance, `!important`, attribute/sibling selectors, arbitrary resource loading, browser
relative units/functions, borders, shadows, gradients, and general transform functions remain
unsupported and fail typed instead of being approximated.

Published modules require Java 25 and libGDX 1.14.2. The release gate qualifies the current
harness 1.2.0 / agent-runtime 2.0.0 profile and the minimum harness 1.1.0 / agent-runtime 1.0.0
profile. V1 remains scoped to LWJGL3 desktop and Scene2D/Scene2D.UI.
