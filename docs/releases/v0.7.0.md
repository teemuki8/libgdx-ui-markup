# libgdx-ui-markup 0.7.0

This additive release introduces immutable application-owned shared component bundles through
MarkupParser.withComponentBundles(Map<String, String>). Bundles use the existing XML component
dialect with namespace-qualified references. Explicit Actor IDs remain unchanged.

Document bytes, elements, components and expansion retain shared bounds. Namespace collisions,
cycles and unsafe XML are rejected with source-located diagnostics. The parser performs no file
or URL imports. Building actors remains confined to the render thread.

Existing parser entry points remain available. The stock preview CLI does not yet expose a
bundle-loading flag; applications provide the bundle map explicitly. See
[ADR 0006](../adr/0006-application-component-bundles.md) and the agentic cookbook.

The three published coordinates are libgdx-ui-markup, libgdx-ui-markup-runtime and
libgdx-ui-markup-harness under io.github.teemuki8. Preview, qualification and IDEA modules are
not Maven libraries. Align the three library modules on 0.7.0 when available.

Publication requires the signed-tag workflow's PUBLISHED result and public artifact verification;
this candidate note does not claim publication or an IDEA marketplace release.
