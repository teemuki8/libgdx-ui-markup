# libgdx-ui-markup 0.2.1

## Highlights

- `HarnessSemanticSink`'s `runtimeCorrelationToken` contract is now documented on the
  constructor: it must equal the `UiFrameCorrelation` correlation token the application
  records per rendered frame, on the render thread. A mismatch silently degrades
  `ui_runtime_compare` to `STALE`/`UNCORRELATED`; the Javadoc names that failure mode and
  the `markup-preview-frame` vs. application-owned token distinction.
- new production-embedding guide (`docs/guides/embedding.md`): the full game-side wiring
  recipe (render-thread build with `Scene2dSession` + `HarnessSemanticSink`,
  `MarkupRuntimeSource` registration, `AgentRuntime` lifecycle, per-frame
  `UiFrameCorrelation` recording, render-thread `RuntimeComparator` coordinator, and the
  drain-before-advance loop order), a typed-status troubleshooting table, and pointers to
  `PreviewMcp`, the harness E2E, and ADR 0002 as the compilable proof;
- README links the embedding guide from the agent-runtime section and the footer.

The published javadoc for `libgdx-ui-markup-harness` carries the corrected contract
documentation; the guide is repository documentation.

## Compatibility

The 0.2.1 API is source- and binary-compatible with 0.2.0 and 0.1.0 (documentation-only
change). Published modules require Java 25 and libGDX 1.14.2; the harness adapter requires
harness 1.1.0.
