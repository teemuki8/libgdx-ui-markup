# libgdx-ui-markup 0.4.0

## Highlights

- exact logical font sizes are now first-class markup: the seven text-bearing built-ins accept
  bounded XML `font`/`font-size` attributes, and the CSS subset accepts `font` plus integer
  `font-size` values with optional `px`; XML overrides CSS independently for family and size;
- the core library uses `gdx-freetype` and bundled Inter Regular to rasterize each requested
  family/size pair exactly, with a bounded render-thread cache, deterministic hinting and
  filtering, skin-owned font disposal, and located diagnostics for unresolved families,
  resource collisions, and cache exhaustion;
- every Scene2D text-bearing style receives the resolved font, including nested SelectBox list
  styles and TextField message fonts, without mutating shared Skin styles or consuming font
  cache entries for non-text widgets;
- the preview derives raster density from the logical/back-buffer ratio, rebuilds fonts and
  layout when density changes, installs FreeType support into JSON skins without replacing
  their existing `default-font`, and owns a separately rasterized diagnostic-overlay font;
- failed preview candidates retain the complete last-good scene, custom skin, exact-size fonts,
  and overlay font; recovery and shutdown dispose every retired or committed font texture;
- Inter Regular 4.1 and its SIL Open Font License are embedded in the core JAR, while strict
  dependency locks and file-exact verification metadata cover the FreeType Java and desktop
  native artifacts;
- the canonical sample, embedding guide, visual qualification corpus, and accepted ADR 0004
  document exact-size UI typography and accessibility reflow. MSDF/SDF rendering, shader
  hooks, and speculative renderer abstractions are deliberately excluded.

## Compatibility

The 0.4.0 Java API is additive relative to 0.3.0. Existing markup without `font-size` remains
valid, and a named Skin `BitmapFont` still resolves when no size is requested. `DefaultSkin`
now uses Inter through FreeType instead of libGDX's built-in bitmap font, so applications may
observe intentional text-metric and line-wrap changes and must ship the matching
`gdx-freetype-platform` desktop natives. Custom JSON skins retain their existing
`default-font`; exact requested sizes use the registered FreeType family.

XML font sizes are integers from 4 through 256. A manager accepts at most 16 families, 2,048
configured BMP characters, and 64 cached family/size pairs. Pseudo-state font-size changes are
rejected with typed diagnostics rather than changing layout during interaction.

Published modules require Java 25 and libGDX 1.14.2; the harness adapter requires harness
1.1.0. V1 remains scoped to LWJGL3 desktop and Scene2D/Scene2D.UI.
